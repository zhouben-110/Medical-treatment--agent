API接口设计

FastAPI后端接口定义

核心接口

API Endpoints
POST /api/chat

发送消息，获取AI回复

请求: { message: string, session_id?: string }
响应: { reply: string, stage: string, symptoms: string[] }
GET /api/history

获取用户历史对话列表

响应: { sessions: [{ id, title, created_at, message_count }] }
GET /api/history/{session_id}

获取指定会话的详细记录

响应: { messages: [{ role, content, timestamp }], diagnosis: string }
GET /api/symptoms

获取症状分类列表

响应: { categories: [{ name, symptoms: string[] }] }

数据模型

Database Schema
-- 用户表
users: id, created_at

-- 会话表
sessions: id, user_id, title, created_at, diagnosis

-- 消息表
messages: id, session_id, role, content, timestamp

-- 症状分类表（预置数据）
symptom_categories: id, name
symptoms: id, category_id, name
