状态定义

State Schema
{
  messages: Message[]        // 对话历史
  symptoms: string[]         // 提取的症状列表
  current_stage: string      // 当前阶段
  confidence: number         // 诊断置信度
  possible_diseases: string[] // 可能的疾病
  treatment_plan: string     // 治疗建议
  need_more_info: boolean    // 是否需要更多信息
}

节点功能

症状分析节点

从用户描述中提取症状，识别关键信息

追问决策节点

判断信息是否完整，决定追问内容

疾病匹配节点

根据症状组合匹配可能的疾病

建议输出节点

生成治疗建议和注意事项
